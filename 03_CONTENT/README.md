# ✍️ 03 · 内容引擎(Content Engine)

> **把主题变成可发布的内容。**
> 你不需要每天想"今天写什么"——你只需要从这里挑一个选题,跑完下面这条流水线。

## 🔁 一条内容的流水线

```
选题(从 02_KNOWLEDGE/选题库 拉)
   ↓
脚本(03_CONTENT/脚本库/<平台>/)
   ↓
文案(03_CONTENT/文案库/小绿书图文 / 朋友圈 / 多平台分发)
   ↓
画面 / B-roll(03_CONTENT/画面-Broll/)
   ↓
封面(03_CONTENT/封面库/)
   ↓
发布 → 05_OUTPUT/<平台>/YYYY-MM-DD_<标题>.md
```

## 📂 子目录

| 目录 | 用途 | 命名规范 |
|---|---|---|
| `03_CONTENT/选题库/` | 选定但还没写脚本的选题(从主题库拉) | `YYYY-MM-DD_<选题名>.md` |
| `03_CONTENT/脚本库/小红书/` | 小红书脚本 | 同上 |
| `03_CONTENT/脚本库/抖音/` | 抖音脚本(分镜表) | 同上 |
| `03_CONTENT/脚本库/视频号/` | 视频号脚本 | 同上 |
| `03_CONTENT/脚本库/B站/` | B 站 / 长视频脚本 | 同上 |
| `03_CONTENT/文案库/` | 长图文 / 朋友圈 / 多平台副本 | `YYYY-MM-DD_<标题>__<平台>.md` |
| `03_CONTENT/画面-Broll/` | 镜头清单(可拆分画面) | `YYYY-MM-DD_<标题>__镜头清单.md` |
| `03_CONTENT/封面库/` | 封面文字 + 视觉说明 | `YYYY-MM-DD_<标题>__封面.md` |

## ⚙️ 关键原则

1. **一份内容优先做透一个平台,再分发**
2. **脚本先写结尾**(因为很多爆款是结尾反转)
3. **开头 3 秒 = 钩子 = 决定生死**
4. **画面 = 关键词 + 一句话分镜,不要写文学**

## 🧠 与 AI 协同

每一步都用 [[../06_SYSTEM/Codex-Prompt]] 对应章节的 Prompt:

| 步骤 | 章节 | 输出 |
|---|---|---|
| 拆选题 | "选题 → 5 个钩子" | 3 条开头脚本 |
| 写脚本 | "脚本生成器" | 一份可直接拍摄脚本 |
| 改文案 | "文案改写" | 5 个平台口播版 |
| 写画面 | "B-roll 分镜表" | 表格化的镜头列表 |
| 想封面 | "封面文案" | 5 个候选标题 + 视觉描述 |

## ⚠️ 反模式

- 选题不用选题库的:回炉重做。
- 脚本缺数据 / 反例的:先别拍,补素材。
- 一次生成 10 条脚本但不发布:等于 0。
