# AI 一人公司 · 知识库自生长

> **核心理念:你不是在整理知识,而是在搭建一个内容自动生产工厂。**

本仓库是一套"**输入源 → 收集入口 → AI 处理 → 知识沉淀 → 内容生产 → 商业化 → 数据复盘 → 运行节奏**"的自生长系统。
每条进来的信息,都要回答一个问题:**它将来能变成什么内容 / 什么产品?**

---

## 🧭 一图看懂

```
输入源 → AI Inbox → 01_AI_BRAIN → 02_KNOWLEDGE → 03_CONTENT → 04_BUILD → 05_OUTPUT → 06_SYSTEM ↺
  捕获        收集入口      AI 处理        主题沉淀        内容生产       商业化      数据复盘      运行节奏
                                                                    ↑
                                                              06_SYSTEM(规则)
```

闭环:**输入源 → 收集 → 理解 → 沉淀 → 生产 → 商业化 → 发布 → 数据反馈 → 优化系统 → 再输入**

## 🚦 每日运行节奏

| 时间 | 动作 | 工具 |
|---|---|---|
| 早间 5 min | 收集:把所有素材先丢进 `00_INBOX/_收件箱` | 语音/截图/链接一键保存 |
| 上午 30 min | AI 处理:清洗 + 分类 + 摘要 → 关联到 `02_KNOWLEDGE` | workbuddy + [[06_SYSTEM/每日处理模板]] + [[06_SYSTEM/Codex-Prompt\|Codex Prompt]] |
| 中午 30 min | 从 `02_KNOWLEDGE/选题库` 拉出 1-3 条 → `03_CONTENT` 生产脚本/文案 | [[06_SYSTEM/Codex-Prompt\|Codex Prompt]] |
| 晚间 20 min | 发布到 `05_OUTPUT` 任一平台,记录数据 | 复盘模板 |
| 周末 60 min | 数据复盘 → 知识升级 → 更新 Prompt/SOP | [[06_SYSTEM/数据复盘模板]] |

## 🪴 成长心法

- **先收集,不判断**:不分类、不挑刺、不完美主义。所有信息无差别进 Inbox。
- **AI 负责理解,你负责判断价值**。
- **每一个笔记都要回答**:这一条将来能变成内容吗?能变成产品吗?
- **每周清一次 Inbox**:处理不完的扔进 `99_ARCHIVE`,别让它拖垮你。
- **让知识自己长大**:数据告诉你什么有效,系统提示词跟着升级。

---

## 🚀 快速开始

1. 把今天看到/想到/听到的任何东西,丢进 `00_INBOX` 对应类型(没有就建)
2. 打开 [[_dashboard]] 看一次全景
3. 按 [[06_SYSTEM/每日处理模板]] 让 AI 帮你过一遍 Inbox
4. 从 `02_KNOWLEDGE/选题库` 里挑一条,按 [[06_SYSTEM/Codex-Prompt]] 让 Codex 帮你写脚本
5. 复制到 `03_CONTENT/脚本库/<平台>/`,发布后到 `05_OUTPUT` 记录数据
6. 周末用 [[06_SYSTEM/数据复盘模板]] 总结,更新 Prompt

> 开始吧。💡
