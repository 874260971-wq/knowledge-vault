# 📥 00 · 输入池 / Inbox

> **黄金原则:先收集,不判断。所有信息无差别进 Inbox,从不分类、不评价、不完美主义。**

## 🎯 这个目录存在的意义

把"想整理再开始"的阻力降到 0。你只需要考虑:**这条信息现在能不能 30 秒内保存下来?** 能,直接丢进来。

## 📂 8 大来源(与 [[_dashboard]] 对应)

| 目录 | 用途 | 何时丢进去 |
|---|---|---|
| `视频-B站-YouTube/` | 看到 / 听到的视频、播客 | 看到时立即收藏链接 + 一句感想 |
| `书籍-文章/` | 读到的书、文章 | 截屏金句 + 原文位置 |

## 📡 自动输入:Horizon 新闻雷达

人工收集之外,知识库接入了 [Horizon](https://github.com/Thysrael/Horizon)(AI 新闻雷达):每天自动抓取 HN / RSS / Reddit / Telegram / Twitter / GitHub 等,AI 评分过滤后生成每日简报,你只需 5 分钟人工筛选有价值的条目进本目录。部署与配置见 [[_Horizon自动收集系统]]。

## 🔁 处理流程

```
00_INBOX/<某类>/<文件名>.md
    ↓ (每天早上 / 周末批量)
01_AI_BRAIN/清洗/<文件名>.md
    ↓
02_KNOWLEDGE/<主题库>/...
    ↓
99_ARCHIVE/(过期的素材,丢弃)
```

## 📌 单一入口

把今天所有要处理的素材,集中粘贴到 [[_收件箱]],再分发给 AI 一条条处理。
这样不会漏,也有"今日清空"的快感。

## ⚡ 一键模板(给 AI 的最简 Prompt)

```
你是我的一人公司助理,这条素材帮我处理:
1. 提取 3 条核心观点
2. 判断属于:选题 / 案例 / 方法 / 工具 / 用户问题 / 灵感 / 商业观察
3. 指出它未来可能变成什么内容或产品
原文:
"""
<粘贴素材>
"""
```

详细 Prompt 见 [[../06_SYSTEM/Codex-Prompt]]。
