# 🧠 01 · AI 理解层(AI Brain)

> **这里放着 workbuddy 处理完的中间产物:摘要、结构化笔记、可直接复用的见解。**

## 🎯 目标

把 `00_INBOX` 里堆的"原料",在不动手的前提下,**全自动** 变成：
- 一句 30 字摘要
- 3 条核心观点
- 1 句"我将来能怎么用它"(选题 / 案例 / 方法 / 工具 …)
- 双链关联到 `02_KNOWLEDGE/` 对应主题库

## 🔁 7 步处理流

```
原材料 → 清洗(去水/纠错) → 分类 → 结构化(Markdown) → 摘要 → 关联(双链) → 增强(补可复用见解) → 商业标注
```

按需执行,不必每条都走完 7 步:
- 一句灵感 → 走 1-3 步
- 一本书 → 必须走完 7 步

## 📂 子目录

| 目录 | 用途 |
|---|---|
| `01_AI_BRAIN/清洗/` | 原文去掉口水话、纠错、标准化标点 |
| `01_AI_BRAIN/分类/` | 给每条打 1-3 个 tag |
| `01_AI_BRAIN/结构化/` | 改成统一 Markdown 模板(本目录里已有) |
| `01_AI_BRAIN/摘要/` | 留核心观点 / step-by-step |
| `01_AI_BRAIN/关联/` | 用双链挂到 `02_KNOWLEDGE` |
| `01_AI_BRAIN/增强/` | AI 补充背景、可平行案例、引用数据 |
| `01_AI_BRAIN/商业标注/` | 标注"可用作 ?课 / ?工具包 / ?种草 / ?咨询" |
