# 🏷 分类

> 给每条素材打 1-3 个 tag,用 [[06_SYSTEM/分类规则]] 的标签体系。

## 输出字段(YAML frontmatter)

```yaml
---
tags: [选题/方法, 内容平台/小红书, 行业/AI]
---
```

## 标签体系(三层)

1. **类型**:选题 / 案例 / 方法 / 工具 / 用户问题 / 灵感 / 商业观察
2. **平台**:小红书 / 抖音 / 视频号 / B站 / 公众号 / 全平台
3. **行业**:AI / 自媒体 / 知识付费 / 个人成长 / 商业 / 其他

## 与主题库的对接

| 类型 tag | 对应主题库 |
|---|---|
| 选题 | `02_KNOWLEDGE/选题库/` |
| 案例 | `02_KNOWLEDGE/案例库/` |
| 方法 | `02_KNOWLEDGE/方法库/` |
| 工具 | `02_KNOWLEDGE/工具库/` |
