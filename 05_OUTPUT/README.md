# 📣 05 · 发布与复盘

> **在这里把内容发出去,然后用数据反推主题库的"含金量"。**

## 🔁 发布流程

```
03_CONTENT/脚本库/<平台>/<文件名>.md
   ↓ 复制到发布后台
05_OUTPUT/<平台>/YYYY-MM-DD_<标题>.md
   ↓ 一周内每天回填当日数据(播放/点赞/收藏/评论/转化)
   ↓ 周末:数据复盘
06_SYSTEM/数据复盘-YYYY-Wxx.md
   ↓ 升维
02_KNOWLEDGE/<某主题库>/...
```

## 📂 子目录

| 目录 | 用途 |
|---|---|
| `05_OUTPUT/小红书/` | 小红书发布记录 + 数据 |
| `05_OUTPUT/抖音/` | 抖音发布记录 + 数据 |
| `05_OUTPUT/视频号/` | 视频号发布记录 + 数据 |
| `05_OUTPUT/B站/` | B 站发布记录 + 数据 |
| `05_OUTPUT/其他/` | 公众号 / 知乎 / 即刻 / 知识星球 |
| `05_OUTPUT/_周复盘/` | 每周复盘笔记(自动跳 `06_SYSTEM/数据复盘-YYYY-Wxx.md`) |
| `05_OUTPUT/_爆款池/` | 5x 平均数据以上的爆款,反哺方法库 |
| `05_OUTPUT/_失败池/` | 不及预期的,反推避免清单 |

## ⚙️ 发布即填模板

每次发布新内容,**5 分钟内**新建一份 `05_OUTPUT/<平台>/YYYY-MM-DD_<标题>.md`,记录:

- 标题 / 话题 / 封面 / 推送时间
- 24h 数据 / 7d 数据
- 评论高频词
- 复盘改进点

防止"发完就忘"。

## 🪜 数据复盘节奏

| 时间 | 复盘内容 | 输出 |
|---|---|---|
| 发后 2h | 看一眼评论 / 完播率 | 紧急挽救(改标题 / 删内容) |
| 发后 24h | 1 日数据 | 标"超预期" / "正常" / "不及格" |
| 发后 7d | 7 日数据(平台长尾) | 进 `06_SYSTEM/数据复盘-YYYY-Wxx.md` |
| 月底 | 月度复盘 | 主题库 star / prompt 升级 |

## 🧰 推荐工具

- 平台后台数据截图 → 上传 → 用 AI 写解读
- Newrank / 飞瓜 / 蝉妈妈(数据榜单)
- 壹伴 / 极客增长(小红书排版 / 数据)

## 🔁 反馈闭环

```
数据爆 → 反推选题/钩子/封面 → 复制到 02_KNOWLEDGE/方法库
数据差 → 反推选题/钩子/封面 → 记录禁忌到 02_KNOWLEDGE/失败清单
```
