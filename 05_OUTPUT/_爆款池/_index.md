# 💥 爆款池

> 数据 ≥ 5x 平均的内容汇集地。
> **目的:复制而非创新。**

## 入库标准

- 24h 播放 ≥ 同类平均的 5 倍
- 或点赞/收藏/转化明显高于同类

## 怎么用

每条爆款问自己:
1. 这条为什么好?(选题 / 钩子 / 节奏 / 封面 / 话题)
2. 我能用同结构重写吗?(用在 [[../../02_KNOWLEDGE/方法库/]])
3. 用户核心需求被怎么满足?(用在 [[../../02_KNOWLEDGE/案例库/]])

## 索引

```dataview
TABLE
  平台,
  数据快照,
  复盘结论
FROM "05_OUTPUT"
WHERE 最终判定 = "⭐ 爆款"
SORT 发布日期 DESC
LIMIT 30
```
