# 💣 失败池

> 数据 < 0.5x 平均 或 0 评论 0 互动。
> **目的:不再踩同样的坑。**

## 入库标准

- 24h 互动 < 5
- 或完播率 < 10%
- 或转化 = 0

## 怎么用

每条失败问自己:
1. 这条为什么失败?(选题 / 钩子 / 节奏 / 封面 / 话题)
2. **我能避开哪个元素就可能不失败?**
3. 把"避免项"写进 [[../../02_KNOWLEDGE/方法库/禁忌清单|方法库禁忌清单]]

## 索引

```dataview
TABLE
  平台,
  数据快照,
  失败原因
FROM "05_OUTPUT"
WHERE 最终判定 = "❌ 失败"
SORT 发布日期 DESC
LIMIT 30
```
