# 📊 数据复盘模板

> **每月一次 + 每周轻量复盘,共同让知识自生长。**

---

## 周复盘(60 min,周末)

### A. 数据层

- 本周发布数:
- 24h 平均播放:
- 完播率(短视频):
- 最高单条 / 最低单条:

### B. 主题层

- 本周命中主题库:`02_KNOWLEDGE/<主题>` N 条
- 主题密度最高主题:
- 主题密度最低主题:

### C. 方法层

- 复用次数最高的方法:
- 删除的方法:

### D. 系统层

- Codex Prompt 改了哪几条?
- 个人定位需要微调吗?

### E. 输出

- 一份 `05_OUTPUT/_周复盘/YYYY-Wxx.md`
- 下周 3 条主推选题

---

## 月复盘(120 min,每月最后一个周末)

### A. 数据曲线

- 月总播放 / 互动 / 转化 / 营收
- 同比环比
- 漏斗(曝光 → 点击 → 互动 → 私域 → 成交)

### B. 主题升级

- 哪些主题升维为方法?
- 哪些方法降维回案例?
- 哪些主题删除 / 归档?

### C. 产品升级

- 课程 / 工具包 / 社群 / 咨询的转化率
- 定价是否调整
- 漏斗哪一步流失最大

### D. 系统升级

- 哪些 SOP 已稳定?
- 哪些 SOP 要废弃?

### E. 输出

- 月度总结文档
- 下月 3 个核心动作
- 半年战略修正(若有)
