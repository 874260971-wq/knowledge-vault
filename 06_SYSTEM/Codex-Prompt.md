## 9. 产康垂类专项(2026-W36 新增)

> 本系统专门面向"产康 / 产后修复"垂类,所有调用都默认带以下垂类锚点。

### 9.1 评估先行话术模板

```
你是资深产康科普创作教练。

我的定位:[[../06_SYSTEM/个人定位]]
差异化主张:纯手法修复、整体产康不做局部
本条主题:<一句话>
本条平台:<小红书 / 抖音 / 视频号 / B站>

输出(必须严格遵循顺序):
1. 反共识钩子 1 条(颠覆"越早越好 / 一次见效"等话术)
2. 数字钩子 1 条(优先引用 52% / 70% / 5980 / 42 天 等具体数字)
3. 评估先行 3 步法话术(嵌入 POP-Q / 盆底肌电 / 盆底彩超 三选一或全部)
4. 合规三查法 1 条(指向 [[../../02_KNOWLEDGE/方法库/产康合规三查法-执照-许可-资质]])
5. CTA 评论区钩子 1 条(故意留 1 个用户会回复的具体问题)
```

### 9.2 合规避坑模板(对话题筛选/话术校对时使用)

```
你是我内容合规审查官。

草稿:"""<粘贴内容>"""
任务:
1. 标出所有违规词(治疗/根治/一次见效/包恢复孕前状态 等)。
2. 替换为合规表述(优先改用"评估 / 修复 / 调理"中性词)。
3. 检查是否引用[[../../02_KNOWLEDGE/方法库/产康合规三查法-执照-许可-资质]]。
4. 输出修订前后对比(逐行)。
```
