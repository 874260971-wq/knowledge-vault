# ✅ 系统自检(每月用)

> **每月最后一个周末,花 30 分钟审一次整套系统。**

---

## 自检清单

### A. 资产层

- [ ] `00_INBOX` 残留 < 7 天未处理 ?条
- [ ] `01_AI_BRAIN/结构化` 与 `02_KNOWLEDGE` 同步率 ≥ 80%
- [ ] 7 个主题库至少 4 个有新增
- [ ] `05_OUTPUT/_爆款池` 不少于总发布数 10%
- [ ] `05_OUTPUT/_失败池` 不少于 5%

### B. 流程层

- [ ] [[每日处理模板]] 在执行(过去 7 天里 ≥ 5 天用过)
- [ ] [[每周节奏]] 和实际偏差 ≤ 1 个时段
- [ ] [[数据复盘模板]] 周/月度填过

### C. 系统层

- [ ] [[个人定位]] 半年没大改
- [ ] [[Codex-Prompt]] 过去一月 ≥ 1 节升级
- [ ] [[分类规则]] 仍覆盖 90% 的新素材
- [ ] [[禁忌清单]] 有更新

### D. 商业层

- [ ] 月度营收有稳定来源
- [ ] 内容 → 私域 → 产品 漏斗跑过 ≥ 1 次
- [ ] 至少 1 个新尝试(新平台 / 新产品 / 新钩子)

### E. 个人层

- [ ] 没连续 14 天没发
- [ ] 没连续 7 天没复盘
- [ ] 没连续 3 天被"完美发布"卡住

---

## 评分

- 全部勾 = A 级
- 缺 1-3 项 = B 级(继续)
- 缺 ≥ 4 项 = C 级 → 砍掉一半动作重做
