# ⏰ 每日处理模板

> **一天的节奏模板。每天围绕这 5 段来执行,不必 100% 准时,但时间段相对固定。**

---

## ☀️ 早间 5:00-9:00(收集)

**做什么**:
- 边刷牙边语音丢 Inbox
- 打开 Horizon 每日简报(飞书推送 / 本地文件),花 5 分钟筛选:与自己定位相关的条目复制进 `00_INBOX/热点-行业新闻/`,附一句"为什么值得记"(详见 [[../00_INBOX/_Horizon自动收集系统]])
- 看一眼昨天哪些未处理

**输出**:
- `00_INBOX/<某类>/...` 多了 N 份
- `00_INBOX/_收件箱.md` 已经清空

**给 AI**:
无

---

## 🌤 上午 9:00-11:00(理解)

**做什么**:
- 打开 `00_INBOX/_收件箱.md`,把所有昨日残留一次性发给 AI
- 用 [[Codex-Prompt]] 第 1、2 节
- 输出进 `01_AI_BRAIN/结构化/`

**输出**:
- N 份结构化笔记

**给 AI**:
`调用 Codex Prompt 1 + 2`

---

## 🌞 中午 11:00-13:00(生产)

**做什么**:
- 从 `02_KNOWLEDGE/选题库` 拉 1-3 条选题
- 用 [[Codex-Prompt]] 第 3、4 节,产出脚本
- 落到 `03_CONTENT/脚本库/<平台>/`

**输出**:
- 1 条脚本已写完
- 选题、脚本、文案、封面任务清单

**给 AI**:
`调用 Codex Prompt 3 + 4`

---

## 🌙 晚间 18:00-21:00(发布)

**做什么**:
- 剪辑 / 写图文 → 发布
- 立即在 `05_OUTPUT/<平台>/YYYY-MM-DD_<标题>.md` 新建记录
- 24h 后回填数据

**输出**:
- 1 条已发布(可不完美)
- 1 份发布记录

**给 AI**:
`调用 Codex Prompt 6`(评论互动)

---

## 🌌 周末复盘(60 min,周六或周日早上)

**做什么**:
- 填 [[数据复盘模板]]
- 更新 [[Codex-Prompt]]
- 在 `05_OUTPUT/_失败池/` / `_爆款池/` 各标 N 条
- 清 `00_INBOX` → `99_ARCHIVE/`(7 天未处理)

**输出**:
- `05_OUTPUT/_周复盘/YYYY-Wxx.md` 写完
- Codex Prompt 至少改了 1 节

**给 AI**:
`调用 Codex Prompt 8`

## 📌 关键心法

> **先做不完美的发布,再迭代。**
> **没发布 = 0;发了 + 复盘 = 进化的最小闭环。**
