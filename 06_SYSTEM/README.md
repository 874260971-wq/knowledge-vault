# ⚙️ 06 · 系统规则 / Personal OS

> **这层是"我自己的操作系统":一切 AI 行为、一切工作流,都从这里开始。**
> 不要在脚本里临时写规则,只在这里写。

## 📂 子文件清单

| 文件 | 内容 | 谁用 |
|---|---|---|
| [[个人定位]] | 我是谁、我做什么、不做什么、写给谁 | 所有 AI 调用的前置 |
| [[分类规则]] | 标签体系(三层) | Inbox / Brain / 沉淀 |
| [[Codex-Prompt]] | AI 处理 Prompt 模板库(7 大动作) | 全流程 |
| [[每日处理模板]] | 一天 5 段时间表 | 自己 / AI 协作 |
| [[数据复盘模板]] | 周末复盘 + 月度复盘 | 闭环 |
| [[每周节奏]] | 周历视图 | 自己 |
| [[禁忌清单]] | 永远不做什么 | 沉淀 |
| [[系统自检]] | 周 / 月自检表 | 自检 |

## 🧠 每次调 AI 时的输入顺序

1. 读 [[个人定位]] → 知道是谁
2. 选 [[Codex-Prompt]] 中对应动作
3. 套 [[每日处理模板]] 的时点说明
4. AI 输出后用 [[分类规则]] 打标签
5. 发布后用 [[数据复盘模板]] 周复盘

## ⚠️ 维护规则

- 所有规则修改先在本目录改,**不在其他笔记中临时改**。
- 改完必须在 [[系统自检]] 加一条记录。
- Codex Prompt 用得顺的,沉淀回 Codex-Prompt 文件,别只写在临时对话。
