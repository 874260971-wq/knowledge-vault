# 🏷 分类规则(标签体系)

> **统一 3 层标签,所有 Inbox / Brain / 沉淀都遵守。**

## 层级 1:类型

- `选题`
- `案例`
- `方法`
- `工具`
- `用户问题`
- `灵感`
- `商业观察`

## 层级 2:平台

- `小红书`
- `抖音`
- `视频号`
- `B站`
- `公众号`
- `全平台`

## 层级 3:行业 / 主题

- `AI`
- `自媒体`
- `知识付费`
- `个人成长`
- `商业`
- `其他`

## 复合标签写法

`类型/平台/行业`

例:`选题/小红书/AI`、`方法/全平台/个人成长`、`案例/公众号/知识付费`

## 自动分配规则

- 如果素材来源是 `00_INBOX/用户问题-私信/` → 自动 `用户问题`
- 如果素材类型是"步骤 / 框架 / 教程" → 自动 `方法`
- 如果带价格 / 测评 → 自动 `工具`
- 如果有时间戳 / 长原文 → 必走 [[Codex-Prompt]] 的"摘要"
- 凡是"和我业务无关"的,标 `冷归档` → 直接进 `99_ARCHIVE/`
