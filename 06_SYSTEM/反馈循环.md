# 🔁 反馈循环 / Feedback Loop

> **这是整套系统的"自生长"引擎。**
> 没有反馈循环,知识库只是"越攒越多"的文件夹。

## 🪩 一句话心法

> **让数据说话,让系统跟着数据升级。**

## 🔁 主闭环

```
发布内容(03_CONTENT → 05_OUTPUT)
   ↓ 数据
   ↓
数据复盘(06_SYSTEM/数据复盘)
   ↓ 主题升级
   ↓
主题库(02_KNOWLEDGE)
   ↓
选题 → 内容(回到顶部)
```

## 🔁 副闭环(系统级)

```
数据 → Codex Prompt 微调
   ↓
Codex Prompt 升级 → AI 处理质量上升
   ↓
AI 处理 → 主题库更高质量
   ↓
主题库 → 选题质量上升 → 数据更好(回到起点)
```

## 🪴 让知识自己长大的 4 个机制

| 机制 | 实现方式 |
|---|---|
| **沉淀机制** | 每天把 Inbox 过一遍进主题库(写入 `02_KNOWLEDGE`) |
| **复用机制** | 选题 / 方法 / 案例 / 灵感 用 `已使用 N 次` 反向标记 |
| **升维机制** | 同主题 5 条以上 → 合并成方法(从笔记升级为体系) |
| **淘汰机制** | 7 天没动 → 归档;3 个月没用 → 标注"待复活" |

## 🛠 自动化清单(可选)

| 动作 | 工具 |
|---|---|
| 自动从视频转写 → 文本 | 通义听悟 / 飞书妙记 / MacWhisper |
| 自动生成封面对比 | Canva + Make |
| 自动抓评论回流 | 飞书多维表 + Webhook |
| 自动按主题库归档 | Obsidian Templater + Dataview |
| 自动发视频 | 剪映 / 蝉妈妈定时发布 |

> **不要为自动化而自动化**。先手动跑 30 天,识别出最大重复项,再工具化。

## 📊 反馈循环的关键指标

- 每周 新增主题库条目 ≥ 5
- 每月 主题库条目被引用 ≥ 10 次
- 每季 至少 1 次方法库升维
- 每年 Codex Prompt 至少 5 节升级
