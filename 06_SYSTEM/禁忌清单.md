## 内容侧

- 🚫 不发"标题党 + 内容空"的内容(规则被识别后会扣流量)
- 🚫 不抄大号原话(平台查重 + AI 查重)

- 🚫 不在 23:00 后发(对你自己累、对流量不好)
- 🚫 不忽略评论区第一条(权重最高)
- 🚫 不与算法赌气:30 条还在 0 推 → 停更复盘,不要硬撑

- 🚫 不在主题库里建"杂项 / 临时 / 待处理"(回退到具体主题库)

## 商业侧
