# 🧱 04 · 项目沉淀(Build)

> **内容不只是曝光,是产品线的"原型试验场"。**
> 这一层把"被反复证明有效的内容"沉淀成**可交付、可售卖、可规模化**的形态。

## 🧠 反哺逻辑

```
爆款内容(03_CONTENT)
   ↓ 反复出现的需求 / 高频被问的问题
   ↓ 选题 → 章节 → 课程大纲 → SOP
   ↓
   ↓
04_BUILD/课程 / 04_BUILD/工具包 / 04_BUILD/社群 / 04_BUILD/企业咨询 / 04_BUILD/SOP
```

## 📂 子目录

| 目录 | 沉淀的产物 | 适用 |
|---|---|---|
| `04_BUILD/课程/` | 系列课大纲、章节、配图、PPT | 训练营 / 知识付费 |
| `04_BUILD/工具包/` | Prompt 模板 / 资料合集 / 自动化脚本 | 低门槛变现 |
| `04_BUILD/社群/` | 社群运营 SOP、入群规则、答疑清单 | 会员 / 知识星球 |
| `04_BUILD/企业咨询/` | 方案 / 报价单 / 案例脱敏版 / 复盘 | B 端客单 |
| `04_BUILD/SOP/` | 自己的生产 SOP,让 AI 复用 | 一人公司的"流水线" |

## 🪜 沉淀路径

1. **内容阶段**:每周看 `05_OUTPUT/数据复盘`,挑爆款
2. **方法阶段**:看 `02_KNOWLEDGE/案例库`,问"是不是同样的人 / 同样问题反复出现"
3. **MVP 阶段**:在 `04_BUILD/` 起一份草稿大纲 / 一份 Prompt 合集 / 一份社群规约
4. **产品阶段**:定价 + 入口(导私域 / 知识星球 / 网店)
5. **交付阶段**:跑 1 期 → 复盘 → 重写

## ⚙️ 反模式

- 没有爆款内容就先开课 → 没流量
- 没有方法库就先做工具包 → 卖不动
- 没有用户就先做社群 → 没人气

> **永远先做内容 → 再做产品。**

| 答疑话术 | AI(基线) + 人(个性化) |
