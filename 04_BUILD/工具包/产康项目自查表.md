# 产康项目自查表(收藏版)

> 花钱之前,把这张表过一遍。能全打 ✅ 的,才值得掏钱。

## 第一步:查机构(缺一项 = 直接走人)

| 检查项 | 怎么查 | 结果 |
|---|---|---|
| 营业执照 | 看挂墙原件,经营范围含"医疗"或"康复" | ☐ |
| 《医疗机构执业许可证》 | 做侵入性/创伤性项目的硬门槛 | ☐ |
| 收费公示 | 价格、项目、时长上墙 | ☐ |
| 发票/收据 | 拒绝"只能转账不开发票" | ☐ |

## 第二步:查人员(操作者 ≠ 销售顾问)

| 检查项 | 说明 | 结果 |
|---|---|---|
| 医师资格证 / 护士执业证 | 医疗行为必须由持证人员操作 | ☐ |
| 健康证 + 培训证明 | 最低要求,仅限非医疗项目 | ☐ |
| 人证一致 | 不要被"我们老师很专业"糊弄过去 | ☐ |

## 第三步:听话术(出现任何一句 = 红旗 🚩)

- 🚩 "一次见效 / 一次归位 / 三次根治"
- 🚩 "包恢复孕前状态"
- 🚩 "肌力才 X 级,再不修就残废了"(焦虑逼单)
- 🚩 "我们这是医院同款技术,但比医院便宜"(医院产康不可"平替")
- 🚩 "先交定金,今天不订就没这个价"

## 第四步:看顺序(顺序对了,钱才花得值)

```
1. 产后 42 天 → 正规医院盆底评估(POP-Q / 肌电 / 彩超)
2. 有问题     → 医院康复科/产康科系统治疗
3. 居家       → 医生指导下凯格尔 / 腹式呼吸
4. 复查       → 按医嘱复评,动态调整
```

⚠️ 顺序反了(先买课、先办卡、先做项目)= 大概率踩坑

## 什么时候必须去医院(不是产康机构)

- 漏尿 / 脏器脱垂感 / 持续腰背痛
- 腹直肌分离 ≥ 2 指且 8 周未恢复
- 产后情绪持续低落 2 周以上
