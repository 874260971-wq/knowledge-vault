## 🔁 沉淀路径

```
00_INBOX/.../<原始文件>.md
   ↓ AI 7 步处理
01_AI_BRAIN/结构化/<原文件名>.md
   ↓ (内容足够分量时)
02_KNOWLEDGE/<主题库>/<主题名>.md
   ↓ 内容生产时直接拉
03_CONTENT/选题库/...
```

## 📌 沉淀的判断标准

不要机械地把每条都拉进主题库,**用以下 4 问**:

1. **是否可独立引用?** → 进 → 否则留 Inbox / Brain
2. **3-6 个月内我会再用一次吗?** → 进 → 否则留
3. **能挂在一个更大的主题词下吗?** → 进 → 进对应主题库
4. **能否用一句话讲清楚它是什么?** → 进 → 不行就先放 Inbox

## 🌱 让知识自己长大的 3 个机制

1. **反向链接**:每次生产内容时,回 `02_KNOWLEDGE` 加"已被使用 N 次"标记
2. **主题聚合**:周复盘时把同主题笔记合并、升维成体系笔记
3. **数据反馈**:爆款结构反推"哪些主题真的吃流量",打星号

## ⚙️ 在 Obsidian 里的打开方式

- 用 **Graph View** 看主题簇
- 用 **Quick Switcher** `Ctrl+O` 直接跳
